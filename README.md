An entry for make.fun's [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty ($2 in USDC): a program that writes one one-line comedy joke, a single line of up to 140 characters, on any subject.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The joke sets up a modern, concrete scene — a smart fridge sending its owner a salad recipe — then turns on the last word: the fridge isn't broken, it's disobedient, so it gets unplugged for insubordination. Deadpan, retellable, no explanation after the punchline. The output is deterministic: every run writes the same line, 78 characters as the gate requires (1 line, 1–140 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
